# Validation and testing

`go run ./tools/ucsync validate` fails with a nonzero exit code for any missing/invalid required file. Validation is also mandatory before promotion, development startup, embedding and release startup. A missing initial snapshot is an error; the application never creates a partial library or downloads a replacement.

Checks include normalized JSON schema fields, supported card types, unique nonnegative IDs, names, numeric cost/stats, unresolved rules, named statuses, safe image filenames, every referenced image, full PNG/JPEG decoding, nonzero images, automatic counts, unreferenced asset files, ISO manifest timestamp, schema version and SHA-256 integrity. Raw AllCards and any saved translations participate in build-time integrity checking. Empty rules are allowed only when explicitly supplied/resolved during normalization.

Sync writes a complete staging directory, validates it, renames the previous directory to a recoverable backup, then installs staging. A failed download/import/validation removes staging and preserves the current dataset. Tests exercise HTTP 403, missing images, malformed JSON, unresolved text, exact raw-byte preservation, no-network imports and interrupted-promotion recovery. The application loads an immutable copy of validated bytes before accepting requests, so an update cannot mix card records from one snapshot with artwork from another.

`go test ./...` tests the data pipeline, API and PDF writer. API tests install a transport that panics if runtime code attempts an outbound HTTP request. Browser assets contain no Undercards URLs. The response CSP restricts connections, scripts and image loading to local resources (with data/blob images allowed). Old runtime sync/import API routes are absent. This is complemented by an executable smoke test from an empty working directory.

The PDF writer is tested for 1, 9, 10, 25, 54 and 250 copies, image reuse, malformed payloads, xref offsets, pagination, cut marks and calibration. A4 is 210 x 297 mm. Cards are placed with a 63 x 88 mm transform, a 3 mm gap, and centered margins (7.5 mm horizontal; 13.5 mm vertical). Embedded image pixels are 744 x 1039, approximately 300 DPI at the exact physical card dimensions. `/PrintScaling /None` requests actual size, but the printer dialog must still use 100%.

`node tests/renderer-data.mjs` tests the actual renderer's RGB packing and PNG 300 DPI metadata. `python scripts/offline_smoke.py` uses the built four-card demo to check embedded frontend/data/images, deck quantities and PDF transport from an empty folder. `python scripts/browser_test.py` adds real canvas/UI checks and saves samples to `output/` using an already installed Chrome/Edge. It blocks HTTPS and Undercards requests via DevTools and checks that all app resource URLs use loopback.

Go tests, Node serialization tests, the build and executable smoke test passed in this workspace. The headless browser failed at Windows process/IPC startup with Access Denied; real canvas rendering and a measured physical print remain manual checks. The user subsequently supplied official AllCards/English JSON and downloaded all 947 required images using the browser helper. The resulting 931-card snapshot passed validation and was embedded in the real executable. An isolated smoke test retrieved all 931 card images and resolved the supplied 25-card KINDNESS deck using that executable from an empty folder. See TODO.md for exact commands and remaining work.

### If Undercards returns 403: manual JSON import

Save the actual JSON response from these pages in your browser (not a login page, HTML error, or copied card list):

- `https://undercards.net/AllCards` -> `AllCards.json`
- `https://undercards.net/translation/en.json` -> `en.json` (needed when card rules are stored separately)

Then:

```powershell
go run ./tools/ucsync import .\AllCards.json --translations .\en.json
```

The requested shorter form also works when translations can be downloaded or rules are already present:

```powershell
go run ./tools/ucsync import .\AllCards.json
```

**Saving AllCards alone does not bypass an artwork 403.** These commands still need missing images during this explicit sync. Any missing rule, unresolved translation, denied download or corrupt image fails the update and keeps the old snapshot. There is no partial-library override.

## 3. Validate and build the real executable

```powershell
go run ./tools/ucsync validate
if ($LASTEXITCODE -ne 0) { throw 'Snapshot invalid; build stopped' }
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
if ($LASTEXITCODE -ne 0) { throw 'Build failed' }
.\dist\uc-print.exe --open
```

`build.ps1` enforces **snapshot validation -> npm run build -> Go build** internally. It embeds the validated bytes. It never downloads data or dependencies. A failed validation leaves an existing release untouched. Use this builder instead of a root-level `go build`; the embedded entry point is generated only after validation.

Copy just `dist/uc-print.exe` elsewhere to distribute/run it. Go, Node, Python, the source folder and `data/` are not required on that machine. After updating a snapshot, rebuild to update the embedded executable. `start.bat` launches the real release if available; otherwise it starts the local development server against `data/`.

## Snapshot files and recovery

```text
data/
  raw/AllCards.json       # original response bytes, never rewritten
  raw/en.json             # exact translation response, when needed
  cards.json
  manifest.json
  assets/cards/*
  assets/powers/*
```

`imageCount` counts unique card artwork files; `powerImageCount` counts status artwork separately. An empty powers directory may be absent when no statuses are referenced. Runtime reads the normalized schema only.

During update, temporary work lives at `data/.staging`. Promotion temporarily retains the previous directory at `.data.previous`; the next sync recovers it after an interrupted rename. Do not delete it during an update. If a crashed sync leaves `.data.ucsync.lock`, close the sync process and remove only that stale lock before retrying. An invalid current snapshot plus a recovery copy fails visibly instead of guessing which to delete.
